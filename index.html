Cara menyambungkan kasir di perangkat lain
☁️ Cara 1: Cloud Sync Otomatis (Rekomendasi)

Tidak perlu kabel atau server khusus. Data otomatis tersinkron lewat Cloud Database!

  1. Buka file POS atau link kasir di HP / Tablet / Laptop lain.
  2. Pada form login, masukkan nama kasir: diah (atau kasir yang sudah didaftarkan).
  3. Selesai! Sistem akan otomatis menarik seluruh sisa stok dan transaksi terdahulu.
  4. Setiap transaksi baru di HP otomatis tersimpan dan terbaca di laptop.
📶 Cara 2: Jaringan Wi-Fi Warkop Lokal (Offline Cepat)

Jika ingin membuka kasir antar perangkat di toko tanpa kuota internet:

  1. Di Laptop kasir, klik dua kali file start_server.bat (atau jalankan node server.js).
  2. Sambungkan HP / Tablet ke jaringan Wi-Fi warkop yang sama.
  3. Buka browser di HP dan ketik alamat IP yang muncul di layar laptop (misal: http://192.168.1.xxx:3000).
